# Система уведомлений Telegram для тендеров

## 🚀 Что было создано

Полная система автоматических уведомлений в Telegram о новых лотах с настраиваемыми фильтрами.

### Основные компоненты:

1. **TelegramService** - сервис для отправки сообщений в Telegram
2. **LotMonitoringService** - сервис мониторинга новых лотов
3. **CheckNewLots** - команда Artisan для проверки лотов
4. **Планировщик задач** - автоматический запуск каждые 30 минут
5. **Панель настроек** - веб-интерфейс для управления уведомлениями

## 📋 Настройка

### 1. Создание Telegram бота

1. Найдите **@BotFather** в Telegram
2. Отправьте команду `/newbot`
3. Введите имя для бота
4. Введите username для бота (должен заканчиваться на "bot")
5. Скопируйте полученный токен

### 2. Получение Chat ID

#### Простой способ (рекомендуется):
1. Запустите вашего бота командой `/start`
2. Бот автоматически пришлет приветственное сообщение с вашим Chat ID
3. Скопируйте Chat ID из сообщения

#### Альтернативный способ:
1. Отправьте любое сообщение боту
2. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates`
3. Найдите `"id"` в разделе `"chat"`

#### Для групп/каналов:
1. Добавьте бота в группу/канал
2. Отправьте сообщение в группу/канал
3. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates`
4. Найдите `"id"` в разделе `"chat"` (для групп ID будет отрицательным)

### 3. Запуск бота

Для работы команды `/start` запустите слушатель бота:

```bash
# Запустить бота (long polling)
php artisan telegram:listen
```

**Альтернатива (для продакшена с HTTPS):**

```bash
# Установить webhook
php artisan telegram:setup-webhook

# Удалить webhook (если нужно)
php artisan telegram:setup-webhook --remove
```

**Важно:** Webhook требует HTTPS соединение. Для локальной разработки используйте `telegram:listen` или ngrok.

### 4. Обновление .env файла

```env
TELEGRAM_BOT_TOKEN=123456789:AABBCCDDEEFFGGHHIIJJKKLLMMNNOOPPQQr
TELEGRAM_CHAT_ID=-1001234567890
TELEGRAM_NOTIFICATIONS_ENABLED=true
```

### 5. Настройка через веб-интерфейс

1. Зайдите в **Настройки → Telegram**
2. Введите токен бота и Chat ID
3. Включите уведомления
4. Нажмите **"Тест"** для проверки
5. Сохраните настройки

## 🔧 Использование

### Команды бота

- `/start` - Получить приветственное сообщение и свой Chat ID

### Автоматический режим

Система автоматически:
- Проверяет новые лоты каждые 30 минут
- Работает с 8:00 до 20:00
- Фильтрует лоты по критериям "Лоты для меня"
- Отправляет уведомления только о новых лотах

### Ручная проверка

```bash
# Через Artisan команду
php artisan lots:check-new

# Через API
curl -X POST http://localhost:8000/api/lots/check-new
```

### Управление планировщиком

```bash
# Для разработки
php artisan schedule:work

# Для продакшена (добавить в crontab)
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

## 🎯 Критерии фильтрации "Лоты для меня"

### Ключевые слова:
- порошок
- стиральный порошок
- стиральный порошок автомат
- полуавтомат и ручная стирка

### Статусы лотов:
- запрос ценовых предложений
- открытый конкурс
- рассмотрение дополнительных заявок
- опубликован прием заявок
- опубликован дополнение заявок
- опубликован
- опубликован прием ценовых предложений

## 🔍 Логи и отладка

### Просмотр логов:
```bash
tail -f storage/logs/laravel.log
tail -f storage/logs/lot-monitoring.log
```

### Типичные ошибки:

1. **"Access denied"** - неверный API токен Goszakup
2. **"Not Found"** - неверный токен Telegram бота
3. **"Chat not found"** - неверный Chat ID

## ⚙️ Дополнительные возможности

### Изменение частоты проверки:
В файле `routes/console.php`:
```php
Schedule::command('lots:check-new')
    ->everyFifteenMinutes()  // Каждые 15 минут
    ->hourly()               // Каждый час
    ->daily()                // Ежедневно
```

### Изменение времени работы:
```php
->between('6:00', '22:00')  // С 6:00 до 22:00
```

### Добавление новых критериев фильтрации:
В `LotMonitoringService.php` измените параметры запроса.
