# Быстрый старт - Telegram бот

## ✅ Готово!

Бот уже запущен и работает! Вы можете:

1. **Написать боту `/start`** - получить приветствие и свой Chat ID
2. **Скопировать Chat ID** из сообщения бота
3. **Добавить Chat ID в настройки** системы

## 🚀 Как использовать

### Получить свой Chat ID

1. Откройте бота в Telegram
2. Отправьте команду: `/start`
3. Бот пришлет вам сообщение с вашим Chat ID
4. Скопируйте Chat ID (например: `524744371`)

### Настроить уведомления

**Вариант 1: Через веб-интерфейс**
1. Откройте: http://127.0.0.1:8000/settings/telegram
2. Вставьте ваш Chat ID
3. Включите уведомления
4. Нажмите "Тест" для проверки
5. Сохраните

**Вариант 2: Через .env файл**
```env
TELEGRAM_CHAT_ID=ваш_chat_id
TELEGRAM_NOTIFICATIONS_ENABLED=true
```

## 🔧 Управление ботом

### Бот уже запущен

Команда `php artisan telegram:listen` уже выполняется в фоне.

### Остановить бота

```bash
# Найдите процесс
Get-Process | Where-Object {$_.ProcessName -eq "php"}

# Или просто закройте окно терминала где запущен бот
```

### Перезапустить бота

```bash
# Остановите текущий процесс (Ctrl+C)
# Затем запустите снова:
php artisan telegram:listen
```

## 📱 Что умеет бот

- `/start` - Приветствие и получение Chat ID
- Автоматические уведомления о новых тендерах (каждые 30 минут)
- Фильтрация по вашим критериям

## ❓ Проблемы?

### Бот не отвечает
- Проверьте что `telegram:listen` запущен
- Проверьте токен в `.env`: `TELEGRAM_BOT_TOKEN`

### Не приходят уведомления
- Убедитесь что Chat ID правильный
- Включите уведомления: `TELEGRAM_NOTIFICATIONS_ENABLED=true`
- Проверьте фильтры в настройках
